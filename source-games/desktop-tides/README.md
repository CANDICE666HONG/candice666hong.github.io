# 桌边潮汐 · 网页作品源码

此目录是作品集内游戏的独立可编辑副本。保留海湾、三类随机生物投放、水波与水流、日夜切换、盲钓和八种鱼图鉴。游戏界面继续采用简短文案；没有成就界面、售卖或货币。

## 开发与重建

在本目录执行 `npm install`，然后可用 `npm run dev` 开发、`npm test` 检查模型、`npm run build` 重建作品集中的静态游戏。

也可以在作品集仓库根目录执行：

```sh
node scripts/build-game.mjs
```

输出为 `projects/desktop-tides/`；不需要在服务器运行 Node.js。构建只清理这一游戏输出目录，不修改作品集首页或其他作品。

## 文件

- `src/`：React 界面、Canvas/WebGL 海湾与交互。
- `data/`：鱼种、昼夜名单及重量显示。
- `art/fish/`：八种钓获插画，透明 WebP。
- `public/assets/`：日夜海湾与小鱼、水母、鳐鱼图像。
- `tests/`：图鉴、遭遇、钓鱼、投放和模拟的模型检查。

网页素材来自当前原型的既有美术，仅作 WebP 编码与钓获插画尺寸优化。日夜背景保留 1672×941，三类生物保留原尺寸，八种钓获插画宽度为 768px。原项目的 PNG 和设计探索没有拷入网页仓库，也没有被改写。

返回链接在游戏画布外，按 `?lang=zh` 或 `?lang=en` 返回作品集对应语言的 `#desktop-tides` 项目位置。语言参数只控制返回链接，游戏自身沿用现有中文界面。

访客的海湾布置和鱼种图鉴保存在浏览器本地，不会随源码或静态文件上传。首次换到网站域名时会开始该域名下的新存档。
